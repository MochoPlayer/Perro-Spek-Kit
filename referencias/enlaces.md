# Enlaces de referencia

## Robot Petoi Bittle (H1)
- [Petoi Doc Center](https://docs.petoi.com/): características, movimientos, conexiones y limitaciones.
- [Petoi – Serial Protocol](https://docs.petoi.com/apis/serial-protocol): cómo se identifican y ejecutan los movimientos.
- [Petoi – Python API](https://docs.petoi.com/apis/python-api): comunicación con el robot desde Python y dependencias.
- Moodle: documentación del robot (API, protocolo serie y Bluetooth).
